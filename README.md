#Projet d'Analyse Socio-Economique avec Gapminder (2007)

Bienvenue sur ce dépôt. Ce projet a pour but d'explorer les grandes tendances mondiales de l'année 2007 à partir des données de référence de Gapminder, en mettant en lumière les liens entre la richesse, la santé et la population des différents pays.

Les Visualisations Proposées
Le projet exploite la bibliothèque Plotly pour rendre l'exploration interactive à travers trois principaux axes :

Un graphique de dispersion croisant le PIB par habitant et l'espérance de vie, avec une distinction par continent.

Un graphique à bulles intégrant la dimension démographique, où la taille de chaque bulle s'adapte à la population du pays.

Une carte géographique mondiale permettant de visualiser la répartition globale de la richesse.

Outils et Technologies Utilisés

Langage : Python

Manipulation des données : Pandas

Visualisations : Plotly Express

Environnement de travail : Google Colab

Comment Lancer le Projet

Télécharge ou clone ce dépôt sur ta machine, ou ouvre le fichier ipynb directement en ligne.

Installe les dépendances nécessaires en exécutant la commande suivante dans ton terminal :
pip install -r requirements.txt

Lance les cellules du notebook pour afficher et manipuler les graphiques interactifs.
